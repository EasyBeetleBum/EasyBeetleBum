# Привет, я Юлия!

Fullstack-разработчик. Специализируюсь на React, TypeScript и NestJS.

## О себе

В разработку я пришла через творчество: мне всегда нравилось созидать — будь то рукоделие, 3D-моделирование или сборка сайтов. Разработка стала логичным продолжением этого интереса, только инструменты теперь цифровые: я собираю работающие сервисы из компонентов, строк кода и продуманной архитектуры.

Мне нравится полный цикл — от вёрстки и UX до настройки API, баз данных и безопасности. Опыт преподавания английского научил меня объяснять сложное простыми словами, адаптироваться под разную аудиторию и доводить начатое до результата. Эти навыки помогают мне в командной работе и в общении с заказчиками.

Сейчас я развиваюсь как fullstack-разработчик и ищу команду, где смогу применять свои навыки, учиться у опытных коллег и участвовать в создании продуктов, которые нравятся людям.

## 🛠 Технологии и инструменты

**Frontend:** React, Redux Toolkit, TypeScript, Feature-Sliced Design (FSD), HTML5, CSS3 (Grid, Flexbox), адаптивная вёрстка, Vite.

**Backend:** NestJS, Node.js, Express, TypeORM, PostgreSQL, MongoDB, JWT, Passport.js, REST API, WebSocket.

**Инструменты:** Git, GitHub, Docker, Jest (Unit/E2E), Swagger, Postman, Linux (базовый).
